# Hanseatic Collection — Design Candidates

Candidate designs for the XStitchLab Hanseatic Collection, beyond the initial five:

1. Three Brothers, Riga
2. Holstentor, Lübeck
3. Bryggen, Bergen
4. Town Hall, Tallinn
5. Artus Court, Gdańsk

All candidates assume 40x40 grid (up to 50x50 for subjects that need it).

---

## Hanseatic Cities — Iconic Landmarks
